# TASK DECOMPOSITION

## Project: Production Portfolio

## M1: WCAG 2.2 AA Audit
- Audit color contrast.
- Audit semantic landmarks.
- Fix accessibility issues related to contrast and landmarks.

## M2: Focus Trap Audit
- Audit keyboard navigation.
- Ensure users are not trapped while navigating with Tab and Enter.

## M3: Strict CSP & Zero Inline Handlers
- Apply a strict Content Security Policy.
- Do not use inline event handlers such as `onclick`.

## M4: Lighthouse 100 Audit
- Audit the portfolio using Lighthouse.
- Optimize assets and page performance to achieve the required Lighthouse score.
